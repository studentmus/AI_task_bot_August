August AI Assist — Полный технический контекст проекта

  Дата редакции: 17.05.2026 (финальная версия дня)

  ---
  Что это

  Асинхронный Telegram-бот на Python 3.11+ (aiogram 3.x). Единый интерфейс
  для управления задачами, Google Calendar и базой знаний (Obsidian/MyBrain).
  Гибридная архитектура:
    - Логирование по сферам → детерминированный FSM (без LLM)
    - Задачи и календарь → LLM tool-calling (DeepSeek)
    - Next-step engine → энергия + GCal + алёрты + проекты + что сделано сегодня

  Dev: Windows 11 + WSL2, рабочая директория /home/adminlinux/AI_task_man
       conda activate taskbot (Python окружение)
  Prod: Ubuntu 24.04 VPS /opt/AI_task_bot_August, systemd unit taskbot.service

  ---
  Стек

  Бот          | aiogram 3.x
  LLM          | DeepSeek API, deepseek-chat, tool calling
  БД           | SQLite + SQLAlchemy ORM
  Календарь    | Google Calendar API — create/update/delete/rename_event
  Планировщик  | APScheduler (CronTrigger + IntervalTrigger)
  Настройки    | pydantic-settings, .env файл
  Obsidian     | Git (add → commit → pull --rebase → push) через asyncio subprocess
  Таймзона     | TASK_TIMEZONE в .env, применяется глобально везде

  Порядок регистрации роутеров (main.py) — КРИТИЧНО

  1. memory_router   — FSM-ответы на плановые пинги (наивысший приоритет)
  2. log_router      — FSM-логирование + ⚙️/📝/🎯 кнопки + slash-команды
  3. motivation_router — /motivate команда
  4. main_router     — NLP-диспетчер свободного текста → LLM

  ---
  Reply Keyboard (LOG_KEYBOARD)

  ТЕКУЩАЯ АРХИТЕКТУРА (Вариант C):
    [📝 Записать →]   [🎯 Что делать?]
    [⚙️ Команды]

  При нажатии [📝 Записать →] → inline keyboard со всеми сферами:
    [🌙 Сон]   [🍽 Питание]   [💪 Тренировка]
    [🌍 Языки] [💡 Идеи]      [🛒 Список]
               [📊 Контекст]
  Callbacks: log_sphere:sleep, log_sphere:nutrition, ..., log_sphere:languages
  Языки → показывает _lang_kb() → [🇩🇪 Немецкий] [🇷🇴 Румынский]

  При нажатии [🎯 Что делать?] → выходит из любого LogState, вызывает next_step
  Обработчик: handle_what_todo_btn (в log_router, без state filter)

  При нажатии [⚙️ Команды] → inline меню:
    [📋 Задачи]    [🧹 Очистить]
    [↩ Отменить]   [💢 Мотивация]
    [📅 День]      [⏹ Стоп]
    [❓ Справка]
  Callbacks: cmd_exec:pending, cmd_exec:cleanup, cmd_exec:undo, cmd_exec:motivate,
             cmd_exec:dayplan, cmd_exec:stop, cmd_exec:help

  ↩ Отменить → показывает _undo_sphere_kb() → picker сфер → undo_sphere:sleep и т.д.

  FSM Логирование (log_handler.py) — БЕЗ LLM

  СОСТОЯНИЯ (states.py — LogState):
    sleep | nutrition | training | german | romanian | ideas | context | wishlist

  INLINE KEYBOARDS:
    При входе в режим: [✗ Отмена]  (callback: cancel_log)
    После каждой записи: [✅ Готово] [📝 Ещё] / [↩ Отменить]
      - Готово  → "✅ Записано в «Label».", выходит из режима, отменяет таймер
      - Ещё     → убирает кнопки, сбрасывает таймер, остаёшься в режиме
      - Отменить → delete_last_log_entry(), git sync

  АВТОВЫХОД: 60 секунд молчания → "⏱ Режим завершён — нет активности 1 минуту."
  Реализация: asyncio.Task per user в _timeout_tasks dict.
  Сброс: при каждой записи и [📝 Ещё]. Отмена: при явном выходе.

  SLASH-КОМАНДЫ:
    /sleep, /meal, /workout, /german (/de), /romanian (/ro),
    /ideas (/idea), /ctx (/context), /wish (/wishlist), /stop, /undo [сфера]
  При вызове с аргументами: пишет запись И входит в LogState (можно продолжить).

  ИСПРАВЛЕНИЯ:
    - Slash-команды в LogState не записываются как лог (~F.text.startswith("/"))
    - "Что делать/нужно/дальше/следующий шаг" корректно эскейпят в LLM
    - [🎯 Что делать?] как текст в любом состоянии → next_step (отдельный handler)

  UNDO:
    /undo [сфера], [↩ Отменить] после записи, ⚙️ → ↩ Отменить → picker
    Sphere aliases: sleep/сон, meal/nutrition/питание, workout/training/тренировка,
                    german/немецкий/de, romanian/румынский/ro, ideas/идеи,
                    ctx/context/контекст, wish/wishlist/список, health/здоровье

  ---
  Каскад роутинга свободного текста (dispatch_text в message_router.py)

  Вызывается только при StateFilter(None).

  Шаг | Триггер                                           | Действие
  -----+---------------------------------------------------+----------------------------
  -0.5 | _TRAINING_REFUSAL_RE + энергия >= 5              | → motivation (пассивный)
  0    | _CANT_SLEEP_RE: "не спится"                       | → лог health.md + рек.
  0.3  | _DAY_PLAN_RE: "спланируй день"                    | → _run_day_plan()
  0.5  | _NEXT_STEP_RE: "что делать", "следующий шаг"      | → _run_next_step()
  1    | _QUESTION_RE: ?, "почему", "есть ли"              | → LLM
  1.5  | _CONVERSATION_RE: "ок", "не хочу", "не надо"      | → LLM как чат
  2    | _OBSIDIAN_LOG_FULL_RE: "запиши в питание: текст"  | → прямой append без LLM
  3    | _OBSIDIAN_LOG_RE: "запиши в питание" (без текста) | → LLM уточнит
  3.5  | _COMPLETION_RE + _LAST_RECOMMENDATION кэш (1ч)   | → авто-лог (без LLM)
  4    | _LOG_CONTINUATION_RE + кэш 15 мин: "ещё съел"    | → прямой append
  5    | _FACT_VERBS_RE: съел/спал/купил...                | → LLM (complete или log)
  5.5  | _MEAL_NOUN_RE: начало с завтрак/обед/ужин         | → LLM
  6    | COMMAND_KEYWORDS: покажи/перенеси/удали            | → LLM
  6.5  | _CONTEXT_EDIT_RE: "ей/её/эту" (местоимения)       | → LLM (move_task)
  5.7  | _READ_REQUEST_RE: прочитай/что записалось          | → LLM (read_bot_log)
  5.8  | _CONTEXT_UPDATE_RE: "мы уже выяснили/ждём..."     | → LLM как чат (не задача!)
  7    | Fallback: rule-based parse_task()                 | → карточка confirm/reject

  ВАЖНЫЕ ПАТТЕРНЫ:
  _COMPLETION_RE — "сделал/готово/выполнил" ОДНИМ словом/фразой (без доп. контекста)
  _CONTEXT_UPDATE_RE — "мы уже выяснили", "сейчас ждём", "новости будут осенью"
                       → LLM как чат, НЕ create_task
  _LAST_RECOMMENDATION — in-memory кэш {user_id: {sphere, entry, ts}}
                         заполняется в _run_next_step() после извлечения sphere
                         TTL 3600с. "сделал" → append_obsidian_log(sphere, entry)

  ---
  Auto-log "сделал" после 🎯 рекомендации

  Когда _run_next_step() получает текст рекомендации:
    1. _extract_rec_sphere(text) — ключевые слова → sphere
    2. entry = первые 150 символов рекомендации
    3. _LAST_RECOMMENDATION[user_id] = {sphere, entry, ts}

  Когда пользователь пишет "сделал/готово/выполнил" (шаг 3.5):
    1. Проверяем _LAST_RECOMMENDATION[user_id], TTL < 1 часа
    2. append_obsidian_log(sphere, entry) — детерминированный лог
    3. Сохраняем в dialog_history
    4. Отвечаем "✅ Записано в {sphere}: {entry}"
    Если нет кэша → обычный FACT_VERBS путь к LLM

  _REC_SPHERE_KEYWORDS — список пар (keywords[], sphere):
    румынск/romanian/duolingo → romanian
    немецк/german/deutsch/anki → german
    тренировк/зал/gym/прогулк → training
    питани/nutrition/поесть → nutrition
    сон/sleep/вздремн → sleep

  ---
  Next-Step Engine (domain/next_step.py)

  Вызывается: _NEXT_STEP_RE / _DAY_PLAN_RE в dispatch_text,
              handle_what_todo_btn из log_handler,
              cmd_exec:dayplan из ⚙️ меню,
              send_next_step_push в 12:30

  КОНТЕКСТ (_gather_context):
    now_str, energy (+ source + sleep_min), free_window (GCal),
    tasks (сегодня), backlog (топ-5 без даты),
    alerts (warning severity),
    today_activity — что уже залогировано сегодня:
      {trained, slept, ate, german, romanian, walked}
    energy_matrix (TTL-кэш 5 мин из _bot/energy_matrix.md),
    project_context (TTL-кэш 5 мин из _bot/project_*.md — только Current State + Next Actions)

  _build_context_prompt() выводит:
    "Сделано сегодня: сон, питание / Ещё не было: тренировка, немецкий"
    "(тренировка была, но прогулки не было)" — если relevant

  СИСТЕМНЫЙ ПРОМПТ (_SYSTEM_PROMPT) — ключевые правила:
    - ОДИН шаг, конкретный, со временем
    - Принципы Ивана: всегда учиться/двигаться, лень ≠ отдых
    - Энергия неизвестна → Medium рекомендация + спросить "оцени 1-10"
    - Recovery иерархия (энергия ≤ 3): сон → еда → прогулка → гитара/чтение
    - В Recovery запрещено: подкасты, языки, работа/код
    - После recovery: "Договорились? Скажи как через полчаса."
    - Project Files: нет Next Actions → 15-мин сессия планирования
    - Frequency Constraints из матрицы

  ФУНКЦИИ:
    suggest_next_step(session, user_id) — один шаг
    suggest_day_plan(session, user_id) — полный план по часам (DAY_PLAN_SYSTEM)
    _call_llm_with_system(system, user_prompt) — универсальный LLM вызов
    _call_llm(user_prompt) — обёртка с _SYSTEM_PROMPT
    _get_today_activity(session, user_id) — dict[sphere: bool] для сегодня
    _is_late_night(now) — после 23:40 → только спать

  После _run_next_step / _run_day_plan → сохраняем в dialog_history
  (чтобы follow-up "сделал / что дальше" имел контекст)

  Гейт 23:40–05:00: возвращает _SLEEP_MESSAGE без LLM-вызова.
